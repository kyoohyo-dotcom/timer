안드로이드 휴대폰용

아이폰은 아직 지원하지 않아요. 안드로이드 휴대폰에서 이 페이지를 열어 주세요.
카카오톡 안에서는 설치 파일이 잘 받아지지 않아요. 오른쪽 아래(또는 위) ⋮ 메뉴에서 다른 브라우저로 열기를 눌러 주세요.
앱 받기 설치가 안 되면 여기 (모든 휴대폰용, 용량 큼)

설치 방법

  1. 앱 받기를 누르고 다운로드가 끝나면 알림이나 화면에 뜬 파일을 눌러요.
  2. "출처를 알 수 없는 앱" 안내가 나오면 설정 → 이 출처 허용을 켜고 뒤로 돌아와요.
  3. 설치를 눌러요. "안전하지 않은 앱" 경고가 나오면 무시하고 설치를 눌러요.
  4. 앱을 처음 열 때 알림 허용을 꼭 눌러 주세요. 그래야 시간이 끝났을 때 알려 줘요.

새 버전으로 바꿀 때

이 페이지에서 다시 받아 설치하면 돼요. 저장해 둔 타이머는 그대로 남아요.
